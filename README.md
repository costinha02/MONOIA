Chat Bot Mono IA
Este trabalho apresenta o desenvolvimento do Chat Bot Mono IA, um sistema web voltado para cadastro, login e gerenciamento de dados. A proposta do projeto foi aplicar, na prática, os conhecimentos adquiridos em programação, criando uma aplicação funcional e próxima de situações reais.

O principal objetivo do Chat Bot Mono IA foi desenvolver um sistema simples, porém completo, que permita ao usuário se cadastrar na plataforma, realizar login, visualizar seus dados, editar informações cadastradas e excluir registros quando necessário. Dessa forma, foi possível compreender melhor como funciona o fluxo de dados dentro de uma aplicação web.

O sistema foi desenvolvido a partir de formulários onde o usuário insere suas informações. Antes de serem enviadas, essas informações passam por validações, garantindo que os dados estejam corretos.

Após o envio, os dados são processados pelo servidor e armazenados no banco de dados. A partir disso, o sistema permite que essas informações sejam exibidas na tela, além de oferecer opções de edição e exclusão.

Um diferencial do projeto é que a edição dos dados acontece na mesma página, o que torna a navegação mais prática e dinâmica. Também foi implementado um sistema de login, garantindo que apenas usuários cadastrados tenham acesso às funcionalidades.

No desenvolvimento do Chat Bot Mono IA, foram utilizadas diversas tecnologias importantes para a construção de aplicações web.

O HTML foi utilizado para estruturar as páginas, o CSS para melhorar a aparência e organização visual, o JavaScript para validações e interações com o usuário, o PHP para a lógica do sistema e comunicação com o servidor, e o MySQL para o armazenamento dos dados.

Além disso, foi utilizado o XAMPP como ambiente de desenvolvimento local.

Pensando na segurança dos usuários, as senhas não são armazenadas de forma simples. Foi utilizada a função password_hash, que criptografa as senhas antes de salvá-las no banco de dados, garantindo maior proteção das informações.

Durante o desenvolvimento, alguns desafios foram enfrentados, como a conexão com o banco de dados, a implementação da edição de dados na mesma página e a validação correta dos formulários.

Esses desafios foram superados por meio de testes, ajustes e prática.

Por fim, o desenvolvimento do Chat Bot Mono IA foi muito importante para consolidar os conhecimentos em programação web, permitindo entender melhor a integração entre front-end e back-end, além da manipulação de dados em banco.

O projeto resultou em uma aplicação funcional e contribuiu significativamente para o aprendizado prático.
